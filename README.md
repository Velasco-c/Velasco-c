## Cómo trabajo

* **Analizo el problema:** comprendo los requisitos y objetivos antes de comenzar una implementación.
* **Planifico la solución:** organizo la estructura del proyecto y defino el enfoque técnico.
* **Desarrollo por etapas:** implemento las funcionalidades manteniendo el código organizado y mantenible.
* **Pruebo y corrijo:** verifico el funcionamiento y soluciono los problemas encontrados.
* **Uso Git:** mantengo los cambios organizados mediante ramas y commits descriptivos.
* **Documento:** procuro dejar una estructura y documentación clara para facilitar el mantenimiento del proyecto.
* **Aprendo continuamente:** reviso lo desarrollado para identificar oportunidades de mejora y fortalecer mis conocimientos.
